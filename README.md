# Python OOP Practice

Small scripts practising object-oriented programming in Python.

## Why this exists
Learning notes in code while studying classes, objects and inheritance.

## What it does
- `opps1.py`: a basic `employee` class with attributes and methods
- `inherit.py`: inheritance with an `animal` base class and a `dog` subclass
- `oop_proj.py`: a menu-driven console app in one class (sign up, sign in, write and send posts)
- `rough.py`: scratch work

## Project structure
```
oops_learning/
├── opps1.py     Classes and objects basics
├── inherit.py   Inheritance example
├── oop_proj.py  Small OOP mini-project
└── rough.py     Scratch file
```

## Getting started
Requirements: Python 3.8+. No external packages.
```bash
git clone https://github.com/abhijha8287/oops_learning.git
cd oops_learning
python oop_proj.py
```
